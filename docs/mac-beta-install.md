# écritu pour Mac(テスター向け)の入れ方・消し方

> 初回のインストールで確かめるまで下書きです。手順や表示が実際と違っていたら、教えてください。

対象は Apple シリコン(M シリーズ)の Mac で、macOS 14以降です。Intel の Mac には入りません。

## 入れ方

1. 受け取った pkg(`ecritu-0.1-<番号>.pkg`)をダブルクリックして開き、画面の案内に従って進めます。途中で管理者のパスワードを求められます。
2. [システム設定] > [キーボード] > [入力ソース] の [編集…] を開き、[+] > [日本語] から『écritu』を追加します。
3. メニューバーの入力メニューから『écritu』を選ぶと使えます。

一覧に『écritu』が出てこないときは、少し待ってからもう一度開くか、いったんログアウトしてログインし直してください。

## 更新

新しい pkg を開くだけです。入力ソースの設定はそのまま使えます。

## 開発用のビルドを入れていた Mac で

`~/Library/Input Methods/ecritu.app`(開発版)が残っていると、同じ名前の入力メソッドが2つ並びます。先に入力ソースから『écritu』を外し、開発版の `ecritu.app` を消してから pkg を入れてください。

## 消し方

1. [システム設定] > [キーボード] > [入力ソース] の [編集…] で『écritu』を外します。
2. 動いている écritu を終了します。ターミナルで次を実行します。

   ```
   pkill -f '^/Library/Input Methods/ecritu\.app/Contents/MacOS/'
   ```

3. `/Library/Input Methods/ecritu.app` をゴミ箱へ入れます。
4. インストールの記録を消します(次に入れ直すときのため)。

   ```
   sudo pkgutil --forget jp.or.pleiades.merope.inputmethod.ecritu.pkg
   ```

5. 学習した内容も消すなら、次を実行します。

   ```
   defaults delete jp.or.pleiades.merope.inputmethod.ecritu.conversion
   ```

## 操作の一覧

| 操作 | 動作 |
| --- | --- |
| Enter | 確定 |
| Space | 変換候補を出す(続けて押すと次の候補) |
| 1〜9 | 候補の選択 |
| ⇧← ⇧→ | 変換の対象を縮める・伸ばす |
| F7、⌃K | カタカナで表示 |
| F6、⌃J、Escape | ひらがなで表示 |
| Shift+字 | ラテン文字の直接入力(Space かかなキーで戻る) |
| 英数、かな | ラテン文字と日本語の切り替え |
| `[` `]` | `『 』` を入れる |
| `{` `}` | `「 」` を入れる |
| z に続けて h j k l | ← ↓ ↑ → を入れる |
| z に続けて . , / - | … ‥ ・ 〜 を入れる |

## 分かっている制約

- 打鍵から表示までに遅れを感じることがあります。
- 設定画面はありません。初期設定のまま使います。
- 追加語彙・抑制語彙の編集はできません。
- Intel の Mac には対応していません。

## 困ったとき

動作がおかしいときは、いつ・どのアプリで・何を入力したかを添えて教えてください。
