# écritu pour Mac(テスター向け)の入れ方・消し方

> 初回のインストールで確かめるまで下書きです。手順や表示が実際と違っていたら、教えてください。

対象は Apple シリコン(M シリーズ)の Mac で、macOS 14以降です。Intel の Mac には入りません。

## 入れ方

1. 受け取った pkg(`ecritu-0.1-<番号>.pkg`)をダブルクリックして開き、画面の案内に従って進めます。
2. 途中で入れ先を選びます。
   - [自分専用にインストール]: 今ログインしているユーザだけが使えます。管理者のパスワードは要りません。入れてすぐ使えます。
   - [このコンピュータのすべてのユーザ用にインストール]: この Mac の全員が使えます。管理者のパスワードを求められます。入れたあと、いったんログアウトしてログインし直してください(ログインし直すまで、入力ソースの一覧に『écritu』が出ません)。
3. [システム設定] > [キーボード] > [入力ソース] の [編集…] を開き、[+] > [日本語] から『écritu』を追加します。
4. メニューバーの入力メニューから『écritu』を選ぶと使えます。

一覧に『écritu』が出てこないとき、選んでも文字が入らないときは、いったんログアウトしてログインし直してください。

入れ先はどちらか片方だけにしてください。両方に入れると、同じ入力メソッドが2つになります。

## 更新

新しい pkg を開き、前と同じ入れ先を選びます。入力ソースの設定はそのまま使えます。

## 開発用のビルドを入れていた Mac で

`~/Library/Input Methods/ecritu.app`(開発版)は、[自分専用にインストール] を選ぶと pkg の版で置き換わります。[すべてのユーザ用] を選ぶときは、先に入力ソースから『écritu』を外し、開発版の `ecritu.app` を消してください。

## 消し方

1. [システム設定] > [キーボード] > [入力ソース] の [編集…] で『écritu』を外します。
2. ターミナルで、入れ先に合わせて次を実行します(動いている écritu を終了し、アプリとインストールの記録を消します)。

   [自分専用] に入れたとき:

   ```
   pkill -f "^$HOME/Library/Input Methods/ecritu\\.app/Contents/MacOS/"
   rm -rf "$HOME/Library/Input Methods/ecritu.app"
   pkgutil --volume ~ --forget jp.or.pleiades.merope.inputmethod.ecritu.pkg
   ```

   [すべてのユーザ用] に入れたとき(管理者のパスワードを求められます):

   ```
   pkill -f '^/Library/Input Methods/ecritu\.app/Contents/MacOS/'
   sudo rm -rf "/Library/Input Methods/ecritu.app"
   sudo pkgutil --forget jp.or.pleiades.merope.inputmethod.ecritu.pkg
   ```

3. 学習した内容も消すなら、次を実行します。

   ```
   defaults delete jp.or.pleiades.merope.inputmethod.ecritu.conversion
   ```

## 操作の一覧

| 操作 | 動作 |
| --- | --- |
| Enter | 確定 |
| Space | 変換候補を出す(続けて押すと次の候補) |
| 1〜9 | 候補の選択 |
| ⇧← ⇧→ | 変換の対象を縮める・伸ばす |
| F7、⌃K | カタカナで表示 |
| F6、⌃J、Escape | ひらがなで表示 |
| Shift+字 | ラテン文字の直接入力(Space かかなキーで戻る) |
| 英数、かな | ラテン文字と日本語の切り替え |
| `[` `]` | `『 』` を入れる |
| `{` `}` | `「 」` を入れる |
| z に続けて h j k l | ← ↓ ↑ → を入れる |
| z に続けて . , / - | … ‥ ・ 〜 を入れる |

## 設定

入力メニューから『écritu』を選んでいるときに、入力メニューの [設定…] を選ぶと [écritu の設定] のウインドウが開きます。変えた設定はすぐに効きます。

変えられるのは、かな漢字変換の候補に関わる次の13項目です。番号と名前は iPhone 版と同じです。値を変えていない項目は、現代的初期設定の値で動きます。

- X.1 かな漢字候補モード
- X.2 旧仮名遣い候補
- X.3 仮名の踊り字候補
- X.4 カタカナ強調表記の候補
- X.5 交ぜ書きの候補
- X.6 旧字体・異体字の候補
- X.7 かなで書く言葉の候補
- X.8 常用漢字による書きかえ
- X.9 常用漢字による書きかえ(後に追加)
- X.10 助数詞型suffixe / 数詞類別suffixe – ka
- X.11 送り仮名の許容形 – orthographe
- X.12 suffixe – me (め/目)
- X.13 数詞の表記 – chiffres

## 分かっている制約

- 打鍵から表示までに遅れを感じることがあります。
- 追加語彙・抑制語彙の編集はできません。
- Intel の Mac には対応していません。

## 困ったとき

動作がおかしいときは、いつ・どのアプリで・何を入力したかを添えて教えてください。
