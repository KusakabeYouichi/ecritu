# 書き言葉(BCCWJ)と 1 位が食い違う同音語・頻度比 3 倍の帯(167 組)

作成: 2026-09-16(edition 2956 時点)。**目視で採用/不採用を決めるための作業用一覧。**
[10 倍の帯](homophone_written_order_review_10x.md)と
[5 倍の帯](homophone_written_order_review_5x.md)を反映した後の状態で測り直した、**その続き**。

## 前回との違い

頻度比の下限を **5 倍から 3 倍**へ下げただけ。他の条件は同じ。

- 書き言葉(BCCWJ)だけで抽出する。話し言葉(CEJC)との突き合わせは
  [別の一覧](homophone_register_divergence.md)。
- BCCWJ 1 位の頻度が **100 回以上**の組に限る。
- écritu の先頭が漢字語の組だけ。かな・カタカナが先頭の組はかな正書の是正で別に扱う。
- 既に判断した 60 組は再掲しない。

**今回は全 167 組が 3 倍以上 5 倍未満の帯に入る。**5 倍以上は前回までで出し切った。
**比が ∞ の組も 0 件。**固有名詞が先頭の組(語彙表に頻度が出ない組)は前の帯で処理済み。

## 見方と判断

BCCWJ 頻度の多い順。**上から順に見て、上位ほど実害が大きい。**判断欄に記号を書く。

- **B** = 書き言葉(BCCWJ)側を採る。先頭を BCCWJ 1 位にする。
- **é** = écritu の現状のまま。
- 別の語を先頭にしたいときは『その語』では? と書く。

**比 3 倍の帯は「どちらが 1 位でも許容」の組が前より増える。**機械と機会、事故と自己のような
近い組がここに現れる。迷ったら é でよい。話し言葉でよく使う側が écritu の先頭なら é が妥当。
