第6章絵文字・顔文字・記号パネル

écritu には、絵文字・顔文字・特殊記号のための3つのパネルがあります。どれもかなキーボードの左下からワンアクションで開けて、国旗や通貨記号は『長押しで名前が分かる』ちょっとした仕掛けつきです。

開き方 — ☺︎ キー

キーボード左下の ☺︎ キー(かな・英字・数字のどのモードでも同じ)が3つのパネルの入口です。

操作開くパネル
タップ[左端最下段 タップ]に割り当てたパネル(初期設定は記号パネル ⌘)
右フリック[左端最下段 右フリック]に割り当てたパネル(初期設定は顔文字パネル ^_^)
長押し[面選択のパレット]が出て、記号・絵文字・顔文字・単漢字・書式化から選べます

タップと右フリックで開くパネルは設定で入れ替えられます(第8章)。同じ列の abc キーを右へフリックしても絵文字パネルが開きます(初期設定)。ホームボタンのある画面の狭い iPhone で、5×2配列を縦画面で使うときは、このキーの代わりに 🌐 キーが出て、右フリック・上フリックでパネルを開けます(第9章)。かなキーボードに戻るには、各パネルの左下にある あい ボタンを押してください。どのパネルにも右下に ⌫ があるので、打ち間違いはその場で消せます。

絵文字パネル

絵文字パネルは、上下にスクロールする絵文字グリッドと、下段のカテゴリーボタンでできています。カテゴリーボタンをタップすると、そのカテゴリーの先頭にジャンプします。カテゴリーは次の8つで、この順に並んでいます。

ボタンカテゴリー
😀顔・人物
🍷食べ物・飲み物
🦆動物・自然
🏀行動・スポーツ
💡オブジェクト
🚗乗り物・場所
🇫🇷国旗(Drapeaux)
❤️シンボル

カテゴリーの中はさらに細かいグループ(顔/手/人物…など)に分かれていて、グループの間には区切り線が入ります。絵文字をタップするとそのまま入力されます。

国旗(Drapeaux) — 長押しで正式名称

国旗カテゴリーは 国 → 海外領土・属領 → その他の旗 の3グループに区切り線で分かれています。先頭はもちろん 🇫🇷 です。

旗のデザインだけでは国名が分かりにくいもの — そんなときは旗を長押ししてください。押している間、国名(フランス語。iOS の地域名データによる)がバブルで表示されます。たとえば 🇫🇷 は『France』、🇩🇪 は『Allemagne』、🇬🇧 は『Royaume-Uni』です。

国・地域コードを持たない旗(ウェールズ 🏴󠁧󠁢󠁷󠁬󠁳󠁿、カナリア諸島 🇮🇨、コソボ 🇽🇰、サルク島 🇨🇶、EU 🇪🇺、交差した日の丸 🎌)は、通常の黒いバブルではなく青いバブルで名称が表示され、国名でないことが分かるようになっています。

ちなみに:Drapeaux(ドラポー)はフランス語で『旗』。écritu の設定値に使われている名称の1つです(第1章)。

記号パネル

記号パネルには8つのカテゴリーがあります。使い方は絵文字パネルと同じで、下段のカテゴリーボタンで切り替え、記号をタップして入力します。カテゴリーボタンは7つ分の幅に並んでいて、最後の[囲み文字]は左へスクロールすると出てきます。

音楽記号は区切り線で3つのグループに分かれています。最後のグループ(𝄞 𝄢 𝄪 𝄫)は、フォントによっては表示されません(□ などになります)。音楽記号は変換でも出せます — おんぷ(♪ ♫ ♬ ♩)、しぶおんぷ(♩)、はちぶおんぷ(♪ ♫)、じゅうろくぶおんぷ(♬)、ふらっと(♭)、なちゅらる(♮)、しゃーぷ(♯)、とおんきごう(𝄞)、へおんきごう(𝄢)、だぶるしゃーぷ(𝄪)、だぶるふらっと(𝄫)。

基本記号の並び順

基本記号カテゴリーは区切り線で3つのグループに分かれています。共通記号(りんごマーク・⌘・中黒・矢印・かぎ括弧)、図形記号(○●△▲☆★※✓ など16個)、約物(ASCII の記号ひととおり)の順です。よく使うものが手前に来る並びにしています。

このうち約物グループの並び順だけ、設定で ASCII(文字コード順・戦略的初期設定)/EBCDIC/ANSI(米国キーボードの打鍵順・初期設定)から選べます(第8章)。前の2グループはどの設定でも同じ並びです。

通貨は長押しでコードが分かる

通貨カテゴリーの記号を長押しすると、押している間バブルで名前が表示されます。

  • 通常の通貨記号 — ISO 4217の通貨コード。€ なら『EUR』、₹ なら『INR』です。
  • ₿ と暗号資産の代替表記 — ティッカーシンボル(₿=BTC、Ξ=ETH など)。
  • 補助単位の ¢ と ₰ — ISO コードを持たないため、緑のバブルで名称(cent/Pfennig)が表示されます。

温度単位は iOS 設定に連動

単位カテゴリーの先頭は温度記号です。iOS 本体の温度単位設定が摂氏なら『℃ ℉』の順、華氏なら『℉ ℃』の順に並び、カテゴリーボタンのアイコンもそれに合わせて ℃/℉ に切り替わります。

顔文字パネル

顔文字パネルは、下段のカテゴリーボタンで分類を切り替えて使います。先頭の3つは特別なカテゴリーです。

ボタンカテゴリー内容
🙂Base (基本)標準セットの顔文字。
⚡️Raccourcis (ショートカット)自分で登録したショートカット語彙(第7章)がここに並びます。よく使う顔文字や定型文の置き場に。
🔎Recherche (検索)読みから顔文字を探せます(下記)。

その後ろに、気分・場面ごとの分類が続きます: Sourire / Rire(笑顔)、Kawaii / Chou(かわいい)、Timide(照れ)、Stress / Panique(焦り)、Déçu / Déprimé(がっかり)、Triste(悲しい)、En colère(怒り)、Surprise(驚き)、Dodo(眠い)、Coucou(挨拶)、Amour(愛)、Excité / Crazy(興奮)、Action(動き)、Bizarre(奇妙)、Héros(キャラ)、Spécial(特殊)。カテゴリー名はフランス語+日本語の併記です。

読みで検索 — 3ステップ

検索カテゴリー(🔎)を開くと、パネル上部に手順が表示されます:『1) 上の文字を選ぶ2) 読みを選ぶ3) 下の顔文字をタップ』。

  1. 横に並んだ五十音の見出し(『全』を選べば全部)から、読みの頭文字を選びます。
  2. 表示された読みの一覧(『えがお』『おこ』など)から1つ選びます。『よみ: えがお』と表示され、[読みを選び直す]ボタンでやり直せます。
  3. [候補をタップして入力]の下に並んだ顔文字をタップすると入力されます。

読みから変換 — パネルを開かない近道

実は、パネルを開かなくても顔文字・絵文字は入力できます。かなのまま『えがお』『ねこ』『くるま』などと打つと、変換候補の中に顔文字や絵文字が混ざって表示されます。^_^ や 🚗 が普通の変換と同じ操作で確定できるので、慣れるとこちらの方が速いはずです。

絵文字の読みは Unicode CLDR の日本語データをもとに整備されているので、『らっこ』🦦 のような新しめの絵文字も読みから出せます。『たいわん』🇹🇼 のように、国名から国旗も出ます。候補に絵文字・顔文字を混ぜるかどうかは、それぞれ設定でオフにできます(第8章 X.16)。絵文字をオフにすると、国旗も以前に選んで学習した絵文字も候補に出なくなりますが、パネルからはいつでも入力できます。
