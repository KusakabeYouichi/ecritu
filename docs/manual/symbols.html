第4章記号・数字・英字の入力

「?」を打つためだけに記号モードへ入る — écritu は、その往復をなくすことを目指したキーボードです。この章では、かなのまま打てる記号たちと、数字・英字の各モードを説明します。

かなモードの右下、改行キーの左にある 、 キーは、文章でいちばんよく使う約物(記号)を 1 キーに集めた、écritu の中心的なキーです。

「元気?」「了解!」「東京・大阪」— こうした文を打つとき、iOS 標準キーボードでは数字/記号モードへの往復が必要でした。écritu ではかなを打つ指の流れのまま、この 1 キーで完結します。まずこのキーの 5 文字を指に覚えさせるのが、écritu 上達の近道です。

未確定中に押すと:変換前の文字が残った状態で 、や 。を打つと、自動的に候補が確定されてから記号が入ります。どの候補で確定するかは設定で選べます(第7章)。

かなキーに埋め込まれた記号

読点キーのほかに、かなキーの「あき部屋」にも記号が入っています。五十音のかなが 5 方向に満たないキーの空き方向を、よく使う記号に割り当てたものです。

  • わキーの下フリック=〜(波ダッシュ)、左フリック=ー(長音)。「10時〜12時」の〜も、カタカナ語の伸ばし棒も、かなのまま打てます。
  • やキーの上フリック=『、左フリック=』(二重かぎ括弧)。書名や強調に使う『』が直接入ります。ゆ・よは右・下フリックです。

2段フリック — 括弧の切り替え

やキーの『』には続きがあります。左右方向のフリックで『または』を選んだあと、指を離さずにそのまま上下へ動かすと、別の括弧に切り替わります。écritu ではこれを「2段フリック」と呼びます。

  1. やキーに触れ、左(』)へフリックします。まだ指は離しません。
  2. そのまま指を上または下へすべらせます。プレビューの文字が ) や 」 に変わります。
  3. 入れたい括弧が表示されたところで指を離すと、その文字が入力されます。

3点リーダーとタブ

あと 2 つ、かなモードに埋め込まれた文字があります。

  • 小(修飾)キーの下フリック=…(3点リーダー)。「それは…」の … が 1 フリックで入ります。
  • 空白キーの上フリック=タブ(⇥)。メモアプリでの字下げや、表形式のテキストで役立ちます。フリック中はキーの上に ⇥ のプレビューが表示されます。

読みで出せる記号(約物)

よく使う記号は、記号モードや数字モードに切り替えなくても読みをかなで打って変換で出せます。読みが完全に一致したときだけ候補の末尾寄りに現れる仕組みなので、普通の言葉の変換の邪魔はしません。「まる」「ばつ」のように名前で打つほうが早い、という場面で使ってください。

部首の字形も同じ仕組みで出せます。部首の名前(2文字以上)をかなで打つと、その字形が候補の末尾寄りに現れます。「くさかんむり」→ 艹、「さんずい」→ 氵、「にんべん」→ 亻 など、康熙部首214種(位置別の字形を含めて245字形)すべてに対応しています。

数字の入力

かな 5×2 なら数字キーが常設

かな配列が初期設定の 5×2 のときは、キーボード最上段に 1〜0 の数字キーが常に表示されています。日付や個数程度の数字なら、モードを切り替えずにそのままタップして入力できます。

数字モード(123 キー)と 3 つの配列

左列の 123 キーをタップすると数字モードに切り替わります(かなに戻るには あい キー)。数字モードの配列は 3 種類から選べます(選び方は第7章、全キーの詳細配列は第8章(続))。

電話番号欄や認証コード欄のような数字専用の入力欄では、écritu は最初から数字モードで開きます。このとき数字配列を clavier にしている場合は、数字専用欄ではテンキーの téléphone 配列で開きます(通常の欄での設定はそのままです)。

calculette(初期設定)電卓式。上段が 7 8 9 で、右下に −()[] キーがあります。
téléphone電話式。上段が 1 2 3 の、iOS 標準に近い並びです。
clavierキーボード式(縦画面専用)。最上段に 1〜0、その下に記号が 2 段並びます。シフトキーで漢数字(一 二 三 … 〇)と別の記号セットに切り替わります。横画面では自動的に calculette になります。

数字キーのフリックに隠れた記号

calculette / téléphone の数字キーは、それぞれの 4 方向に記号を持っています。通貨・数学記号・郵便記号など、代表的なものを挙げます。

ほかにも、1 に矢印(← ↑ → ↓)、6 に = < > ≠、7 に「」: ;、9 に | \ ` ^、最下段に () [] {} などの括弧類が割り当てられています。図の方向は初期設定のフリック方向(écritu 方向)のもので、Apple 方向設定では割り当てが変わります。全キー×全方向の一覧は第8章(続)を参照してください。

℃ と ℉:3 キーのフリックには温度記号があり、iPhone の温度単位の設定(摂氏/華氏)に連動して ℃ または ℉ が表示されます。

書式化数値の入力 — 単位・金額・日付

「1,234.5 hPa」「-¥1,000」「2026年3月4日 (水)」のような書式付きの数値・金額・日付を、ドラム(回転式の選択リスト)で単位や書式を選びながら組み立てて、1 回の確定でそのまま入力できるモードです。かなモード左下の ☺︎ キー(かな左下キー)を長押しすると開きます。かな入力に戻るには下段左端の あい キーをタップします。

下段には 5 つのカテゴリーキーが色分けされて並びます: kg(SI基本単位)・m/s²(SI組立単位)・hPa(固有の名称を持つSI組立単位)・€(金額)・📅(カレンダー)。前回使ったカテゴリー・単位・接頭辞・トグル状態は記憶され、次に開いたとき同じ状態から始まります。

単位と金額

左側はテンキー(並びは設定「数字配列」の書式化数値入力に従い、calculette または téléphone)で、数字 3 行の下に ±(符号反転)・0・小数点キーが並びます。小数点キーの表示と入力は設定「format numérique」の Séparateur décimal(. か ,)に連動します。数字は 8 桁まで入力できます。

右側は上から、プレビュー(確定される文字列がそのまま見えます)、単位ドラム、トグル行です。ドラムを回すと記号と読みのカード(例: 「hPa ヘクトパスカル」)が表示されます。SI単位系の 3 カテゴリーでは単位ドラムの左に接頭辞ドラムが付き、T・G・M・k・h・(なし)・c・m・μ・n・p の 11 種から選べます(質量の基本は g なので、k を選ぶと kg になります)。金額カテゴリーは ¥ $ € £ ¢ ₩ ₹ ₽ ₺ ฿ ₫ ₴ の 12 通貨です。

hPa のカテゴリーには、SI と併用できる非SI単位として t(トン)と l(リットル)も入っています。リットルは接頭辞ドラムと組み合わせて hl・cl・ml のように使えます。リットルの字形は設定の「リットルの記号」で l / L / ℓ から選べます(第7章)。

sep mil千位区切りのオン/オフ。オンのとき 3 桁ごとに区切り記号(設定の Séparateur de milliers)を挿入します。
espace(単位カテゴリー)数値と単位の間に空白を入れるか(1000 hPa / 1000hPa)。
avant / après(金額カテゴリー)通貨記号を数値の前に置くか後に置くか(¥1000 / 1000€)。通貨ごとの慣用に合わせた初期値を持ち、負数は -¥100 のように負号が先頭に出ます。
↵(確定)プレビューの文字列をそのまま入力します(変換を経ない直接入力)。数値が空のまま押すとかな入力へ戻ります。

N·m のような組立単位の中の積の記号は、設定「format numérique」の単位の積の記号(U+00B7 / U+22C5 / U+0020)で置き換えられます。

温度の度記号(°C / ℃)は設定「degré」の字形で表示・入力されます。

カレンダー(日付)

📅 カテゴリーでは月間カレンダーが表示されます。< > で月を送り、日をタップして選ぶと、プレビューに書式化された日付が表示されます。書式はプルダウンから実例(「3月4日」「2026年3月4日 (水)」など)で選べ、候補の系統は設定「カレンダー」の日付書式(日本式/フランス式/英国式/米国式)で切り替わります。週の開始曜日・曜日の言語・日曜/金曜/土曜列の色も同じ設定カードで選べます。

英字の入力

abc キーと 3 つの配列

左列の abc キーをタップすると英字モードに切り替わります。配列は 3 種類です(選び方は第7章、詳細は第8章(続))。

AZERTY(初期設定)フランス式のフルキーボード配列。1 キー= 1 文字でタップ入力します。
QWERTY一般的な英語配列のフルキーボードです。
3×3 フリックかなと同じ 3×3 のフリック型。a キーの上=b、右=c のように、1 キーに複数の文字が入っています。

シフトキー — 大文字の入力

  • タップ:次に打つ 1 文字だけ大文字になります(1 文字打つと自動で解除)。もう一度タップすると解除です。
  • ダブルタップ、または長押し:シフトロック(Caps Lock)。解除するまで大文字が続きます。ロック中にタップすると解除されます。

長押しでアクセント文字

AZERTY / QWERTY では、文字キーを長押しするとアクセント付き文字のパネルが開きます。たとえば a の長押しで a à á â ä æ ã å ā ă ą が並び、指を離さず左右にスライドして選び、離すと入力されます。e(è é ê ë …)、c(ç …)、o(ö œ ø …)、u(ü ù …)、n(ñ …)、s(ß …)など、ヨーロッパ言語の文字を一とおりカバーしています。

3×3 フリック配列では:長押しアクセントは使えません。アクセント文字が必要な場合は AZERTY / QWERTY を選んでください。

縦画面の AZERTY / QWERTY — ⌫ と記号の位置

縦画面で AZERTY / QWERTY を使うときは、キーが小さくなりすぎないよう、最下段の配置が少し変わります。

  • 削除キー ⌫ は英字最下段の右端に移ります(AZERTY では右シフトの位置、QWERTY では行末に追加)。
  • 空白キーの並びには、いつもの ⌫ の位置に @、空白の左に /、右に . と - の記号キーが入ります。メールアドレスや URL の入力がモード切り替えなしで進みます。

横画面ではまた別のタイプライタ型レイアウトになります。第8章(続) 横画面を参照してください。

英字の候補 — 欧文サジェスチョン

英字モードで文字を打っていくと、候補バーに入力中のつづりで始まる単語のサジェストが表示されます。候補をタップすればつづりの残りを打たずに入力できます。長い単語や、つづりがあいまいな単語のときに便利です。

サジェストの語彙は次の 2 系統が合流して表示されます。

  • 追加語彙・学習した語 — 自分で登録した語や、これまでに入力した語。常に先頭側に表示されます。
  • 同梱の頻度順語彙 — 英語・フランス語・イタリア語 各約15,000語、ドイツ語 約60,000語(複合語が多いため深く収録)。アクセント記号(voilà、perché)やドイツ語名詞の大文字(Polizei)も正しい表記で補完されます。差別語や強い卑語は提案から外しています(自分で打つことは制限しません)。第7章「欧文サジェスチョンの言語」で言語別にオン・オフできます(初期設定はすべてオフ)。

大文字で打ち始めると候補も先頭が大文字になります(Natur → Natural。全部大文字で打てば候補も全大文字)。空白で区切って 2 語目以降を打つときは、いったん語句全体で探し、一致が無ければ直前の空白の後ろから探し直します。追加語彙の空白入りの語句(銘柄名など)は先頭から打てば語句ごと補完され、ふつうの単語は文中のどこでもサジェストされます。

ワインの略語(A.O.C.、D.O.C.G.、g.U. など)は、ピリオドを打たずに小文字で打つと補完されます(aoc → A.O.C.、docg → D.O.C.G.)。
